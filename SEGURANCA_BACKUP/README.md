## Escopo

O snapshot preserva código, firmware, simulador, testes, scripts e documentação versionados. Não inclui bancos locais, configurações pessoais, tokens, ambientes virtuais, caches, logs nem modelos grandes que estavam excluídos pelo processo de segurança.

**Importante:** a branch é uma cópia versionada do repositório, não um backup completo do computador. Para preservar memórias e preferências do JARVIS, siga `ULTRON/SEGURANCA_E_BACKUP.md` e faça também uma cópia local do banco pelo recurso de backup do JARVIS e dos arquivos de configuração privados.

Não apague nem force atualizações da branch de segurança.
