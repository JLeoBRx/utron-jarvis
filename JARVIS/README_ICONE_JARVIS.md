# J.A.R.V.I.S. — Ícone oficial

A interface agora usa o novo emblema visual do J.A.R.V.I.S. como identidade principal.

## Aplicações

- ícone da aplicação Qt/PySide6;
- ícone da janela principal;
- ícone da bandeja do Windows;
- botão flutuante do J.A.R.V.I.S.;
- fallback automático para o ícone padrão caso o arquivo não esteja disponível.

## Arquivos

`assets/jarvis_icon.ico` — ícone Windows com múltiplas resoluções.

`assets/jarvis_icon.png` — versão principal transparente.

`assets/jarvis_fab_128.png` — versão otimizada para o botão flutuante.

O código não depende de caminho absoluto: os arquivos são procurados na pasta `assets` ao lado de `jarvis_hud.py`.
