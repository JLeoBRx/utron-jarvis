# ULTRON

Inteligência computacional local para Windows: percepção multissensorial, World Model e
Neural Graph persistentes, planejamento com verificação e recuperação, voz offline e um
HUB neural procedural. Cérebro principal: Ollama local.

- Instalação e uso: [`ULTRON/README_ULTRON.md`](ULTRON/README_ULTRON.md)
- Auditoria do JARVIS e decisões da transformação: [`ULTRON/ARCHITECTURE_REPORT.md`](ULTRON/ARCHITECTURE_REPORT.md)

```
ULTRON\INSTALL_ULTRON.bat     instala (Python 3.11 + Ollama)
ULTRON\START_ULTRON.bat       inicia o HUB neural
python ULTRON\TEST_ULTRON.py  testes
```

O projeto anterior (JARVIS) está no histórico do Git: `git checkout 53e5a31 -- JARVIS`.
